# Reading desk

A browser page of three blogs for the category in front of you. Eight categories, three publication sources each. Divya asks on this same page. Matching stays in the browser. It does not sign in to Cursor and it does not call a model.

From this directory:

```bash
npm run dev
```

Open http://127.0.0.1:47231

The question box is on this page. Answers come from the publication catalog in `lib/catalog.ts`. A category desk shows three blogs. Ask can also return sources that are kept in the catalog but not shown on that desk.
