# Reading desk

A browser page that recommends three articles for a design category. The articles come from one shared library of approved publications. A category filters by subject, not by which site published the piece.

Matching and ranking run in the browser from a verified cache of articles retrieved on 19 Oct 2026. The page does not invent titles, and it does not call a model. Excerpts are labeled as excerpts.

From this directory:

```bash
npm test
npm run dev
```
